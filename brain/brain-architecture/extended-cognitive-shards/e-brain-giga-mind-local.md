# Brain Architecture Context Engineering System
## Cognitive Shard-Driven Project Context Synthesis

**Objective:** Implement intelligent context engineering that automatically maintains accurate project "brain" files using cognitive shard coordination, preventing AI hallucination through continuous project awareness and synthesis. [1](#70-0) 

---

## Trigger System

**MUST** activate context engineering when:
- Git commits touch `src/`, `lib/`, `apps/`, or `packages/` directories
- Manual trigger via `/refresh-context` command
- Project initialization detected
- Cognitive shards identify context drift

**SHOULD** skip execution if:
- More than 500 source files detected (token explosion prevention)
- Running in read-only mode
- Context refresh occurred within last 5 minutes

## Cognitive Shard Coordination

### Primary Shards Activated
- **Architect Shard**: Project structure analysis and component mapping
- **Data Architect Shard**: Schema detection and relationship mapping  
- **Archaeologist Shard**: Historical pattern recognition and change detection
- **Engineer Shard**: Build system analysis and dependency mapping
- **Performance Optimizer Shard**: Context optimization and token management

### Shard Communication Protocol
```
Architect → Data Architect: "Component dependencies detected"
Archaeologist → All Shards: "Historical patterns for similar structures"
Performance Optimizer → System: "Context budget: 75% of limit"
```

## Context Engineering Workflow

### Phase 1: Project Snapshot & Analysis
**MUST** execute comprehensive project scanning:

```bash
# Capture current state
git rev-parse --short HEAD > .brain-context/current-sha.txt
find src lib apps packages -type f -name "*.js" -o -name "*.ts" -o -name "*.jsx" -o -name "*.tsx" -o -name "*.py" -o -name "*.go" 2>/dev/null | head -500 > .brain-context/file-tree.txt

# Auto-detect project ecosystem
[ -f package.json ] && echo "node" > .brain-context/ecosystem.flavour
[ -f go.mod ] && echo "go" > .brain-context/ecosystem.flavour  
[ -f requirements.txt ] && echo "python" > .brain-context/ecosystem.flavour
```

## Guardrails & Safety

**MUST NEVER**:
- Store raw secrets or sensitive data in context files
- Include `.env`, `config/secrets.*`, or credential files
- Generate context for more than 500 source files without explicit approval
- Overwrite critical project files during context generation

**MUST ALWAYS**:
- Exclude sensitive patterns from context synthesis
- Validate generated context against project reality
- Maintain context freshness indicators
- Provide rollback capability for context changes
