# Rule Effectiveness Tracker Module 
  
**Objective:** Track which rules are most effective and identify opportunities for rule enhancement based on actual usage patterns. 
  
## New Memory Files  
- `memory-bank/rule-performance.md` - Success rates and outcomes by rule  
- `memory-bank/rule-conflicts.md` - When rules interfere with each other  
- `memory-bank/rule-improvements.md` - Suggested enhancements based on usage  
  
## Integration with Existing System  
Analyzes entries in `consolidated_learnings.md` to identify rule-related insights and improvement opportunities.
