# Predictive Knowledge Assistant  
  
**Objective:** Analyze task context to predict which memory bank information will be needed and surface it proactively.   
  
## New Memory Files  
- `memory-bank/context-predictions.md` - What information is likely needed  
- `memory-bank/access-patterns.md` - How memory bank is actually used  
- `memory-bank/knowledge-optimization.md` - Most effective knowledge organization  
  
## Integration with Task System  
Works with task resumption capabilities to ensure relevant context is immediately available when continuing work.
